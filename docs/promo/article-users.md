# 把 B 站离线缓存，导出得干干净净（用户向 · 母稿）

> 定位：面向「B站普通用户」的核心产品稿。以 7 段式骨架写成，是酷安 / B站 / 小红书等平台改稿的**内容母版**。下载统一指向 GitHub Releases v1.6.1。

---

## 1 / 痛点钩子

很多人都有这样的经历：网速不好、或者想着「先缓存下来路上看」，于是把视频缓存在了 B 站 APP 里。等真想把缓存找出来——发现它藏在 `Android/data` 深处，普通文件管理器根本点不进去；就算进去了，也是一堆 `entry.json`、`blv/*.blv` 这种看不懂的碎片文件，既不能看，也拷不出去。

**明明是我缓存的视频，却「拿不出来」。**

## 2 / 一句话价值主张

**BiliDownOut 能把这些离线缓存，整理成一个个能看、能分享的 MP4，并按 UP 主归档。** 你缓存的视频，重新变得「属于你」。

## 3 / 是什么

BiliDownOut 是一个把哔哩哔哩 APP 离线缓存**干净导出**的工具：读取缓存里的视频文件和元信息，分片拼接、重命名，导出成正常播放的视频。它是一款免费、开源的 Android 应用（当前 **v1.6.1** 稳定版）。

> 透明说明：它是开源项目 [10miaomiao/bili-down-out](https://github.com/10miaomiao/bili-down-out) 的**增强分支**，我在原版基础上补齐了「按 UP 主分组」「番剧独立」「多维排序」「多选批量」等更顺手的能力。

## 4 / 场景化功能演示

与其罗列功能，不如看几个真实场景：

### 场景 A：一屏平铺找不到想要的视频
缓存一多，列表像没有目录的长文。以前只能一屏屏往下翻。
→ 现在：**按 UP 主自动分组**，每组带 UP 主头像、按中文拼音排序。想看谁的视频，点开对应分组就是，一目了然。

### 场景 B：缓存里躺着动漫 / 影视，混在一堆“未知”里
番剧和影视本来没有 UP 主，过去容易被当成“未知 UP 主”塞进角落。
→ 现在：所有番剧·影视**统一归入单独的「番剧·影视」分组**，UP 主的内容也更干净。

### 场景 C：想知道哪个缓存最占空间
手机空间告急，但不清楚该删哪个。
→ 现在：**按大小排序**，最占空间的缓存排到最前面，快速锁定目标。

### 场景 D：一次只想导一批
缓存几十个，一个个导出很累。
→ 现在：导出记录支持**多选 + 批量操作**，一次处理一批。

## 5 / 上手 / 安装

1. **下载**：从下方 GitHub Releases 取 debug APK 安装。
2. **授权**：
   - Android 13+：需安装并授权 [Shizuku](https://shizuku.rikka.app/)，即可无 root 访问 `Android/data` 深处的缓存。
   - Android 12 及以下：在系统设置授予「存储权限」（管理所有文件）即可。
3. **使用**：打开 App 扫描缓存 → 勾选要导出的 → 选好目标文件夹，完成。

> 提醒：本包为 debug 签名。首次安装需允许「安装未知来源应用」；后续同签名版本可直接覆盖安装。Android 5.0（minSdk 21）及以上可用。
