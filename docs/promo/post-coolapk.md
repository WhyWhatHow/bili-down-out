# 【应用推荐】把 B 站缓存干净导出的工具（v1.6.1 稳定版）

> 酷安 · 发版体 · 务实向。由 `docs/promo/article-users.md` 改稿。

---

## 一句话
B 站缓存的视频藏在 `Android/data` 深处，普通文件管理器进不去、出来也是碎片。这个 App 帮你把它们**按 UP 主整理成能看能拷的 MP4**。

## 为什么值得试
- 缓存再多也能 **按 UP 主分组**，带头像、中文拼音排序，找缓存不像大海捞针。
- **番剧·影视单独成组**，不再混进"未知 UP 主"。
- **按大小排序**，一键找出最占空间的缓存。
- 导出记录支持**多选 + 批量删除**，一次处理一批。

## 需要的权限
- **Android 13+**：需安装并授权 [Shizuku](https://shizuku.rikka.app/)（免 root 访问 Android/data）。
- **Android 12 及以下**：授予「存储权限」（管理所有文件）即可。

## 上手
1. 下载 debug APK 安装（首次要允许「安装未知来源应用」）。
2. 装好后打开 → 授权 → 扫描缓存。
3. 勾选要导出的，选个目标文件夹，搞定。
