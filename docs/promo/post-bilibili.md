## 一、专栏文案（可独立发布）

> 你的 B 站缓存，能「拿」出来吗？

在 B 站缓存了视频，想在别的地方看、想分享给朋友——却发现它在 `Android/data` 深处，普通文件管理器进不去，拷出来的还是一堆 `blv` 碎片。

**BiliDownOut** 帮你把它整理成正常可看的 MP4，按 UP 主归档：

- **按 UP 主分组**，带头像、中文拼音排序，再也不用在一长串缓存里翻找。
- **番剧·影视单独一组**，不混进"未知 UP 主"。
- **按大小排序**，快速找出最占空间的缓存。
- 导出记录**多选 + 批量**处理。

**怎么用（3 步）**
1. 安装后授权：Android 13+ 需要安装并授权 [Shizuku](https://shizuku.rikka.app/)；低版本授予「存储权限」。
2. 打开 App 扫描缓存。
3. 勾选要导出的 → 选目录 → 完成。

**下载 / 仓库 / 反馈**：https://github.com/WhyWhatHow/bili-down-out

> 透明说明：本项目 fork 自开源项目 [10miaomiao/bili-down-out](https://github.com/10miaomiao/bili-down-out)，在分组、排序、批量等方面做了增强，感谢原作者。
